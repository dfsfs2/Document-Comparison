# Issue tracker

Use GitHub Issues in `dfsfs2/Document-Comparison` for issues and specs.

- Read an issue and its comments with `gh issue view <number> --comments`.
- Publish a ticket with `gh issue create --title <title> --body-file <path>`.
- Use the strings in [triage-labels.md](triage-labels.md) for triage.
- PRs as a request surface are off.
